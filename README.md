# Feedplaner

Instagram-Feed planen wie im echten Profil: Bilder reinziehen, Reihenfolge anpassen, Beitragstexte schreiben.

## Funktionen

- Profilkopf mit Profilbild, Benutzername, Name, Bio und Zahlen
- Raster mit 3 Bildern nebeneinander im 3:4-Format
- Bilder per Drag & Drop oder Knopf hinzufügen
- Beitragstext pro Bild, mit Kopieren-Knopf
- Reihenfolge ändern (am Computer per Ziehen, am Handy mit Pfeilen)
- Export und Import als JSON-Datei

## Nutzung

Einfach `index.html` im Browser öffnen oder auf Vercel deployen. Kein Build-Schritt nötig.

## Speicherung

Alles bleibt lokal im Browser auf dem jeweiligen Gerät. Kein Konto, kein Server.
Tipp: Regelmässig exportieren. Auf dem iPhone die Seite zum Home-Bildschirm hinzufügen, damit Safari die Daten nicht löscht.
